# Ohm's Law Calculator

## Purpose: calculates current with voltage and resistance from user

## Input Format: Asks user for Voltage (volts) and then Resistance (ohms)

## Build and Run Commands:
### Compile the Progam: g++ -std=c++17 -Wall -Wextra -pedantic src/main.cpp -o build/app 
### Run Program: ./build/app

### Example Output: For input: 12 4 Output: Current: 3 A

## Limitations: The program doesn't prevent users from entering numbers that may be unrealistic.

## Reflection: The program was tested for both a valid and invalid input to make sure the program runs and calculates correctly.
